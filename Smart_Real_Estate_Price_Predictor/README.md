# Smart Real Estate Price Predictor – Bengaluru

An applied Machine Learning and Full-Stack Web Application designed to predict residential property prices across **Bengaluru, Karnataka, India**.

Valuations are driven primarily by **property location, geographic density, area classification, and surrounding infrastructure**, completely independent of room configurations.

---

## 🌟 Key Highlights & Architectural Principles

- **Zero Bedroom / Bathroom Bias**: The machine learning model strictly omits bedroom count, bathroom count, BHK, washroom, and balcony counts to isolate the empirical impact of geographical location, land area, and community infrastructure.
- **Authentic Bengaluru Dataset**: Trained and evaluated on Kaggle's comprehensive `Bengaluru_House_Data.csv` comprising 13,300+ property transactions across 240+ verified Bengaluru localities.
- **Multi-Model Regression Benchmarking**: Compares Linear Regression, Ridge Regression, and Random Forest Regressor using Scikit-Learn `Pipeline` and `ColumnTransformer` with zero data leakage.
- **Production-Ready Web Application**: Responsive interface built with Flask, HTML5, CSS3, JavaScript, Chart.js, and SQLite.
- **RESTful API**: Includes JSON endpoints for headless programmatic property valuations.
- **Audit History**: Automatically logs user predictions to an embedded SQLite database.

## 🚀 Quickstart Guide (VS Code on Windows)

Open **Visual Studio Code** and launch a **PowerShell** or **Command Prompt** terminal.

### 1. Navigate to Project Directory
```powershell
cd Smart_Real_Estate_Price_Predictor
```

### 2. Create and Activate a Python Virtual Environment
```powershell
# Create virtual environment
python -m venv venv

# Activate virtual environment on Windows
venv\Scripts\activate
```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 4. Run Data Preprocessing
Preprocesses the raw dataset, removes outliers, cleans square footage, and drops all forbidden room features:
```powershell
python preprocessing.py
```

### 5. Train and Benchmark the Machine Learning Models
Compares Linear Regression, Ridge, and Random Forest models on an 80/20 train-test split, selects the best model, and saves artifacts into `model/`:
```powershell
python train_model.py
```

### 6. Start the Flask Web Application
```powershell
python app.py
```

### 7. Access the Web Application
Open your web browser and navigate to:
```text
http://127.0.0.1:5000
```

## 📊 Model Evaluation & Benchmarks

All models were evaluated on an unseen 20% hold-out test set (2,515 properties) using the exact same location and surrounding features:

| Model Architecture | R² Score | Mean Absolute Error (MAE) | Root Mean Squared Error (RMSE) |
|---|---|---|---|
| **Linear Regression (Production)** | **62.71%** | **Rs. 41.05 Lakhs** | **Rs. 103.78 Lakhs** |
| **Ridge Regression** | 62.36% | Rs. 41.02 Lakhs | Rs. 104.27 Lakhs |
| **Random Forest Regressor** | 61.55% | Rs. 36.63 Lakhs | Rs. 105.38 Lakhs |

> **Note on Model Accuracy**: The website and application report genuine empirical accuracy (~63% R²). Because bedroom, bathroom, and balcony features are intentionally excluded to isolate pure location dynamics, the model captures nearly two-thirds of all market price variation strictly from location density, construction area classification, and society infrastructure.

## 🔍 Feature Breakdown

### Features Used by the Model:
1. `location_clean`: Standardized Bengaluru locality (one-hot encoded for 240+ localities).
2. `total_sqft_numeric`: Total property area in square feet.
3. `area_type`: Construction classification (`Super built-up Area`, `Built-up Area`, `Plot Area`, `Carpet Area`).
4. `availability_category`: Possession readiness (`Ready To Move`, `Under Construction`, `Immediate Possession`).
5. `society_presence`: Binary indicator (1 if located within a registered society/gated community, 0 otherwise).
6. `location_frequency`: Neighborhood transaction density derived from listing frequency.

### Features Deliberately Excluded (Strict Rule):
- ❌ `size` / `BHK` / `bhk`
- ❌ `bedroom` / `bedrooms`
- ❌ `bath` / `bathroom` / `bathrooms`
- ❌ `balcony` / `balconies`
- ❌ `room count` / `washroom`

## 📡 REST API Documentation

### Endpoint: Predict Property Price
- **URL**: `/api/predict`
- **Method**: `POST`
- **Headers**: `Content-Type: application/json`

#### Example Request:
```json
{
  "location": "Whitefield",
  "total_sqft": 1200,
  "area_type": "Super built-up Area",
  "availability": "Ready To Move",
  "society": 1
}
```

#### Example Successful Response (HTTP 200):
```json
{
  "success": true,
  "predicted_price_lakhs": 52.37,
  "predicted_price_inr": 5237000,
  "formatted_price": "₹ 52.37 Lakhs",
  "price_per_sqft": 4364.17,
  "location": "Whitefield",
  "total_sqft": 1200.0,
  "area_type": "Super built-up Area",
  "availability": "Ready To Move",
  "society_presence": 1,
  "model_used": "Linear Regression"
}
```

#### Example Error Response (Unknown Location, HTTP 400):
```json
{
  "success": false,
  "error": "Location not available in the trained Bengaluru dataset. Please select a supported location."
}
```

## 🛡️ Error Handling & Safety Features

- **Unknown Location Handling**: Unknown or unsupported localities are safely flagged with a user-friendly message rather than hallucinating arbitrary encodings.
- **Negative Price Clamping**: Real estate values are clamped to realistic positive minimums based on regional construction costs.
- **Missing Model Safety**: If model files are absent, the application alerts the user to run `train_model.py` instead of crashing with an unhandled exception.
- **Cross-Platform Compatibility**: All file paths use `pathlib.Path` ensuring flawless operation on Windows, macOS, and Linux without hardcoded user directories.
