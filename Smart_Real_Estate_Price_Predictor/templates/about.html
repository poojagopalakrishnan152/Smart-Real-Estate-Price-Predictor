About Smart Real Estate Price Predictor

An applied Machine Learning and Full-Stack web application designed to predict residential property prices across Bengaluru, Karnataka, using pure geographic, spatial, and surrounding environmental features.

🎯

Core Objective

Provide home buyers, real estate developers, and urban analysts with reliable, data-backed property price estimations based on neighborhood infrastructure, location density, and construction area classification.

📊

Bengaluru Dataset

Trained on the comprehensive Bengaluru House Data dataset from Kaggle containing over 13,300 transaction listings across 240+ verified Bengaluru localities.

💻

Technology Stack

Built cleanly with Python 3, Flask, Scikit-Learn, Pandas, NumPy, SQLite, HTML5, CSS3, JavaScript, and Chart.js without unnecessary complex framework overhead.

Key Architectural Choice

Why Bedroom & Bathroom Features Are Excluded

Most conventional housing price predictors rely heavily on room counts (1 BHK, 2 BHK, 3 BHK, bathroom counts). However, in a dynamic metropolis like Bengaluru, land value, commercial IT cluster proximity, and neighborhood infrastructure dictate the fundamental asset valuation.

By intentionally eliminating size (BHK), bath, and balcony columns during preprocessing, this project demonstrates:

  • Location-First Valuation: How geographical placement in tech hubs (e.g. Whitefield, Indiranagar, Electronic City) creates premium value independent of internal layout.
  • Area Classification Impact: How Plot Area vs. Super built-up Area vs. Carpet Area reflects varying land-to-structure proportions.
  • Density & Community Metrics: Leveraging locality listing frequencies and gated society infrastructure to quantify neighborhood demand.
  • Pure Environmental Signals: Preventing the regression model from relying on room count heuristics that mask true location-based pricing disparities.

Machine Learning Methodology

End-to-end pipeline ensuring high generalization and zero data leakage.

1. Data Preprocessing

Converts non-standard square footage (ranges like "1200 - 1400", unit conversions for Sq. Meters, Sq. Yards, Acres), removes duplicates, standardizes locality names, and filters extreme outliers.

2. Feature Engineering

Derives locality frequency (transaction density), standardizes availability schedules into 3 clear business categories, and encodes gated society presence.

3. Model Benchmarking

Compares Linear Regression, Regularized Ridge, and Random Forest Regressors on an 80/20 train-test split using scikit-learn Pipelines and ColumnTransformers.
